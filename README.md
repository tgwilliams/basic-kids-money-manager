# basic-kids-money-manager
Basic web app for kids to understand money management.

## Features
- Big pie chart showing where the money went, by category (hover or tap a slice for details)
- Simple form: how much, when, what category, and where
- List of every purchase, newest first, with a button to delete one
- Reset button to start over
- Saves automatically in the browser (localStorage), so no account or server is needed

## Running it
Open `index.html` in any web browser. That's it, there's no build step.
